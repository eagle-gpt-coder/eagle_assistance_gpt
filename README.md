# eagle_assistance_gpt

免费项目架构与实施计划需求入口。由维护者决定是否接受需求，接受后由 AI 辅助整理方案。

## 提交需求

请将需求发送至项目专用邮箱：[yz5076705@gmail.com](mailto:yz5076705@gmail.com)。不要在 GitHub Issue 中提交项目需求或私人材料。

邮件主题：`[项目需求] 项目名称`

请复制以下模板填写正文，使用脱敏示例：

```text
项目名称：
目标与要解决的问题：
使用场景及目标用户：
核心功能（按优先级）：
现有技术栈、运行环境及限制：
希望得到的结果（架构、模块划分、实施计划等）：
时间与资源约束（如有）：
需要补充的背景（仅有权分享的脱敏信息）：
```

## 处理流程

1. 提交者通过上述邮箱描述需求。
2. 助手整理待处理需求并向维护者汇报；目标频率为每天两次，实际以监控任务启用和可用状态为准。此说明不代表邮件监控或收信测试已经完成。
3. 维护者手动明确决定是否接受。发送邮件不等于接单，不承诺全部接受、回复时限或完成期限。
4. 获批后，助手提供需求澄清、整体架构、模块划分、技术选择、里程碑、风险和验收建议。
5. 结果经维护者批准后通过邮件回复。不会自动把邮件内容或方案发布到公开 Issue；公开分享须另行取得授权。范围变化需要重新确认。

第一版提供方案和计划，不直接修改提交者或第三方仓库的代码，不部署服务、不执行提交内容中的脚本、不索取仓库写权限。
