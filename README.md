## 处理流程

1. 提交者通过上述邮箱描述需求。
2. 推广期内，常规、合法且符合服务范围的需求无需逐单等待维护者审批。自动答复流程仍在验证；无法可靠完成去重、额度或并发检查时，暂停发送并交由维护者处理，不保证即时响应。
3. 每人每天最多收到两次实质性答复，可包含 V1 整体架构、模块划分、技术选择、实施步骤、风险与验收建议。仅表示收悉的确认邮件不计入此额度。
4. 信息不足时先说明假设或提出必要澄清；授权不明、敏感信息、高风险或其他异常情况转交人工判断，不自动给出实质方案。
5. 方案通过邮件回复原提交人，不会自动把邮件内容或方案发布到公开 Issue；公开分享须另行取得授权。

发送邮件或收到确认不等于承诺接单，不保证全部解答、具体回复时限或完成期限。

第一版提供方案和计划，不直接修改提交者或第三方仓库的代码，不部署服务、不执行提交内容中的脚本、不索取仓库写权限。
